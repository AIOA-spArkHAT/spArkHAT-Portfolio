# AIOA spArkHAT 🐾 | Human-Controlled AI Engineering

[![AIOA Website](https://img.shields.io/badge/Portfolio-sparkhat.eu-1769aa)](https://sparkhat.eu/) [![Source](https://img.shields.io/badge/GitHub-AIOA--spArkHAT-181717?logo=github)](https://github.com/luciferprosun/AIOA-spArkHAT) [![Documentation](https://img.shields.io/badge/Docs-GitBook-3884ff)](https://sparkhat-research.gitbook.io/sparkhat-reserch-docs/)

Building **AIOA spArkHAT**, a local-first experimental runtime for AI-assisted engineering with explicit human approval, provenance checks, bounded model advice, durable receipts and independent verification. The goal is **provider independence without surrendering authority to a model**.

### AIOA: local historical endurance evidence

![GOLD24](https://img.shields.io/badge/GOLD24-local%20PASS-328a3f) ![Checkpoints](https://img.shields.io/badge/Checkpoint%20records-722-blue) ![Active time](https://img.shields.io/badge/Reported%20active%20time-86%2C426s-6f42c1)

The September 2026 local report describes 86,426 reported active seconds and 722 linked checkpoint records. Checkpoint integrity was reviewed, **but the raw test bundle is not publicly released**, the tested candidate is not the current public main, replay attempts were zero, and the result is **not independent certification of the current product**. See the [evidence review](https://github.com/luciferprosun/AIOA-spArkHAT/blob/main/docs/launch/GOLD24_LOCAL_EVIDENCE_REVIEW_20261013.md). **Gold72 is planned, not completed.**
